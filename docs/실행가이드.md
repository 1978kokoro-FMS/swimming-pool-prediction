# 🚀 수영장 이용객 예측 시스템 실행 가이드

## ⚡ 빠른 시작 (추천)

### 방법 1: 배치 파일 사용 (가장 쉬움)
1. `실행.bat` 파일을 **더블클릭**
2. 자동으로 Flask 앱이 실행됩니다
3. 브라우저에서 `http://127.0.0.1:5000` 접속

## 📋 수동 실행 방법

### 1단계: 명령 프롬프트 열기
- **Windows 키 + R** 누르기
- `cmd` 입력 후 Enter

### 2단계: 폴더로 이동
```bash
cd C:\Users\kokor\Desktop\swimming-pool-prediction-main
```

### 3단계: Flask 앱 실행
```bash
python app.py
```

### 4단계: 브라우저에서 접속
브라우저 주소창에 입력:
```
http://127.0.0.1:5000
```

## ❌ 하면 안 되는 것

### 잘못된 방법 1: HTML 파일 직접 열기
- ❌ `index.html` 파일을 더블클릭
- ❌ 브라우저에서 "파일 열기"로 index.html 선택

**이렇게 하면 CORS 오류가 발생합니다!**

### 잘못된 방법 2: file:// 경로로 접속
- ❌ `file:///C:/Users/kokor/Desktop/...`
- ✅ `http://127.0.0.1:5000` (이렇게 해야 함)

## 🛠️ 문제 해결

### 문제 1: "python을 찾을 수 없습니다"
**해결**: Python 설치 필요
1. https://www.python.org/downloads/ 접속
2. 최신 버전 다운로드 및 설치
3. ⚠️ 설치 시 "Add Python to PATH" 체크!

### 문제 2: "Flask를 찾을 수 없습니다"
**해결**: 패키지 설치
```bash
pip install -r requirements.txt
```

### 문제 3: CORS 오류 (현재 문제)
**원인**: HTML 파일을 직접 열었음
**해결**: 
1. Flask 앱 실행: `python app.py`
2. 브라우저에서 `http://127.0.0.1:5000` 접속

### 문제 4: "포트가 이미 사용 중입니다"
**해결**: 다른 Flask 앱이 실행 중
1. Ctrl+C로 이전 앱 종료
2. 또는 작업 관리자에서 python.exe 프로세스 종료
3. 다시 실행

### 문제 5: 기상청 API 호출 실패
**확인 사항**:
1. 인터넷 연결 확인
2. API 키 유효성 확인
3. `python test_weather_api.py` 실행하여 테스트

## 💡 자주 묻는 질문

### Q1: 왜 HTML 파일을 직접 열면 안 되나요?
**A**: Flask는 웹 서버입니다. HTML 파일을 직접 열면 서버가 실행되지 않아:
- API 호출 불가 (CORS 오류)
- 데이터베이스 접근 불가
- 동적 기능 작동 안 함

### Q2: 매번 실행해야 하나요?
**A**: 네, 사용할 때마다 Flask 앱을 실행해야 합니다.
- 사용 후 Ctrl+C로 종료
- 다음 사용 시 다시 실행

### Q3: 다른 컴퓨터에서도 접속할 수 있나요?
**A**: 기본 설정은 로컬만 가능합니다.
다른 컴퓨터에서 접속하려면 `app.py` 마지막 줄을:
```python
app.run(debug=True, host='0.0.0.0', port=5000)
```
로 변경하세요.

### Q4: 앱을 백그라운드에서 실행할 수 있나요?
**A**: 가능하지만 권장하지 않습니다.
개발 서버는 테스트용입니다. 실제 운영에는 다른 방법이 필요합니다.
